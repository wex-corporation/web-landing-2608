# assets

## hero.jpg — 서막 실사 사진

`weblock-landing/assets/hero.jpg` 파일을 넣으면 첫 화면이 **해당 부동산 실사 사진**으로 시작한다.
스크롤을 내리면 형광 보라 밴드가 아래에서 위로 훑고 지나가며 사진이 벗겨지고,
그 자리에 같은 건물의 레고 버전이 드러난다. 파일이 없으면 이 단계를 건너뛰고
레고 건물에 보라 스윕만 지나간 뒤 곧바로 다음 챕터로 이어진다 (오류 없음).

권장 사양
- 가로 사진, 최소 2000px 폭 (레티나 대응), 1~2MB 이하로 압축
- 3D 씬의 완공 컷과 비슷한 **전면-우측 3/4 앵글**일수록 전환이 자연스럽다
- 배경 톤이 어두운 저녁/블루아워 사진이면 씬과 가장 잘 붙는다
- 위치 미세조정은 `css/style.css` 의 `.hero-photo-img { background-position }`

파일명을 바꾸려면 `js/v2/main2.js` 의 `PHOTO_SRC` 를 수정한다.
